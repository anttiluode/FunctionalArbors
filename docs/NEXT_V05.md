# After v0.5

The delay-cable question is no longer the immediate unknown. v0.5 shows it can happen in a free branching body when a useful generic local turnover operation is available.

The next harder questions are about the **plasticity grammar** and **representation capacity**.

1. Replace the single U-detour move with a small unbiased library of local topology-preserving swaps. Can soma credit select delay-producing moves without being handed the useful primitive?
2. Move from two sources to four or more. Ask for a vector of arrival delays and test whether the body grows a multi-tap physical delay embedding rather than one scalar lag.
3. Train on a multiscale temporal signal and measure whether the path-length spectrum becomes correspondingly multiscale.
4. Only then consider 3-D. The milestone is not prettier dendrites; it is whether 3-D geometry expands the set of independently controllable delays at fixed material budget.
