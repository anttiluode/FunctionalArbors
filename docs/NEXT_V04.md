# After v0.4: free-field geometric delay

v0.4 proves the geometry-only mechanism in a controlled cable where local structural moves are explicit.

The remaining synthesis question is harder:

> Can a field-grown branching arbor discover the same delay without being handed two cables or a plaquette detour grammar?

The clean next design should keep v0.4's binary bond physics and add **turnover** to the PhaseStigmergy-style exposed interface:

1. binary occupied/empty material;
2. fixed K for every occupied bond;
3. current-based eligibility on occupied links;
4. soma task contrast as the global credit;
5. fixed mass: each new frontier cell is paid for by pruning one low-value occupied cell;
6. connectivity-aware pruning so the organism can reroute without simply dying;
7. measure skeleton path lengths before reading any wave timing.

Primary pass condition:

- reward vs shuffled credit changes binary skeleton path-length difference in the requested sign;
- independent wavefront delay changes with the same sign;
- anti-credit reverses both;
- all arms have identical occupied-cell count and identical K values.

That would earn the stronger phrase **self-grown geometric delay arbor** rather than the controlled-cable capability proved in v0.4.
